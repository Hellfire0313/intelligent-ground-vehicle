023-Tier Lane Following

Steering confidence degrades gracefully as lane visibility drops, rather than failing outright when one wall disappears.

Tier 1

Both Walls Visible

PD control on the midpoint between left and right yellow lines. Highest confidence. Uses a lookahead blend for smoother cornering.

Tier 2

One Wall Visible

Estimates lane centre using a learned lane width, EMA-filtered from Tier 1 observations. Falls back to a 280px default until calibrated.

Tier 3

No Walls Visible

Holds last steering for a set number of frames, then creeps straight, then stops. Triggers a pivot-scan if a horizontal line was previously detected.

03Obstacle Avoidance

Powered by the Intel RealSense D455 depth camera. The robot analyses a forward corridor in real time and transitions through a full escape-and-recover state machine when an obstacle is detected.

DETECT
0.90 m
WARN / ESC2
0.70 m
E-STOP
0.35 m
Dodge

Lateral Avoidance

Steers around the obstacle using a combined depth + lane-space score to pick the clearest side. Direction is locked until the corridor clears.

Escape

Reverse Manoeuvre

Two-phase reverse-then-forward manoeuvre. ESCAPE2 is a gentler variant triggered at warning range. Escalates to full ESCAPE if E-STOP is hit mid-manoeuvre.

Recover

Return to Lane

Blends steering back toward normal lane following over a configurable number of frames once the corridor is confirmed clear. Cooldown prevents re-triggering.

If no RealSense is connected, obstacle avoidance is silently disabled and lane following runs normally.
04ArUco Marker Navigation

The webcam feed is scanned for DICT_4X4_50 markers every frame. Only 4 IDs are used — the dictionary supports up to 50, leaving room for custom extensions.

IDBehaviourClears On
01Turn leftLeft wall gap confirmed
02Turn rightRight wall gap confirmed
03Stop — halts robotID 4 or timeout
04Resume — clears stop, suppresses false exitsImmediate
IDs 05–50 are unused and available for extension — speed zones · lap counters · U-turns · checkpoints · task triggers · any custom behaviour via ARUCO_ID_MAP
05Control Pipeline

Perception on the Raspberry Pi 5 feeds a steering and safety decision layer; commands go out to the Arduino Mega over UART.
